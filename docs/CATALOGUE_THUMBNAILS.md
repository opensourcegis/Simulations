# Catalogue previews

All 23 simulation cards use locally hosted, responsive WebP previews (22 subjects; the original and React ortho labs share their subject). The old inline SVG sketches have been removed. Every image has a descriptive alternative, explicit 16:9 dimensions, lazy loading, and 480/960-pixel sources. Hover enlargement respects reduced-motion preferences. No 3D renderer or third-party image host is needed on the catalogue page.

## Artwork

`scripts/thumbnail-studio.js` is an offline Three.js studio with consistent lighting, metallic equipment, cast shadows, glass optics and textured terrain. It reuses the simulation's survey aircraft, buildings, trees and land-cover material. LiDAR scan points come from `buildScanLine`. The SfM preview is generated by the actual image-based initializer and incremental solver, not synthetic reference coordinates. The remaining scenes are editorial illustrations of the lesson's apparatus and geometry, not measurements or simulation result screenshots. Equipment, rays, pixels, orbital distances and lever guides may be enlarged for recognition at card size. Do not use preview dimensions for teaching calculations.

The globe/map uses the repository's existing Earth texture. No external stock imagery or generated-image service is required. Assets are committed so normal builds and GitHub Pages deployment do not require Chromium or a rendering step.

## Regeneration and checks

With Chromium available through remote debugging on port 9222:

```sh
npm run thumbnails:render
# Or regenerate selected subjects:
npm run thumbnails:render -- camera ranging
npm run test:thumbnails
npm run build
npm run test:catalogue:browser
```

The renderer starts a temporary Vite server on port 4180 and closes it afterward. `PHOTO_CDP_URL` overrides the Chromium endpoint. The browser check uses the production preview at `http://localhost:4173/Simulations/`; override with `PHOTO_BASE_URL`. It verifies every image's decoding and dimensions, all card mappings, responsive layouts, filter/search behavior and reduced motion, and writes a contact sheet and catalogue screenshot to `/tmp` for review.
